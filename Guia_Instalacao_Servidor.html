Guia de Instalação e Atualização do Infoboard

Este guia prático explica como implantar e atualizar o painel do Infoboard (NPX & PrixChat) no Servidor Principal da empresa. O sistema rodará de forma invisível em segundo plano (como um serviço Windows) e poderá ser acessado por qualquer TV ou computador da rede local.

1. INSTALAÇÃO INICIAL NO SERVIDOR

Passo 1: Preparar o Ambiente

  1. Acesse o Servidor Principal (via Acesso Remoto/RDP).
  2. Instale o Node.js (baixe a versão "LTS" em nodejs.org e instale clicando em Next).
  3. Crie uma pasta no servidor onde o sistema vai morar. Por exemplo: C:\Sistemas\Infoboard

Passo 2: Copiar os Arquivos

  1. No seu computador (Davi.Oliveira), copie os arquivos da sua pasta de projetos.
    2. ⚠️ ATENÇÃO: NÃO COPIE a pasta node_modules. Ela possui milhares de arquivos pesados que iremos recriar no servidor rapidamente no próximo passo.
  2. Cole os arquivos na pasta que você criou no Servidor (C:\Sistemas\Infoboard).
  3. Importante: Certifique-se de que o arquivo .env (onde ficam suas chaves, emails e senhas) foi copiado também. Como ele é um arquivo "oculto" no Windows, às vezes passa despercebido.

Passo 3: Instalar as Dependências

  1. No servidor, abra o Prompt de Comando (CMD).
  2. Navegue até a pasta do sistema digitando: 
    cd C:\Sistemas\Infoboard
  3. Instale os pacotes (isso vai recriar a pasta node_modules perfeitamente adaptada ao servidor): 
    npm install

Passo 4: Liberar o Acesso na Rede Local (Firewall)

Para que as TVs e os computadores dos gerentes consigam abrir o painel pelo IP, precisamos avisar o Windows do servidor para não bloquear a porta 3000.

  1. Abra o PowerShell como Administrador.
  2. Cole o comando abaixo e aperte Enter: 
    New-NetFirewallRule -DisplayName "Acesso TV Infoboard" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow

Passo 5: Ativar o "Cão de Guarda" (PM2)

O PM2 é a ferramenta profissional que manterá o sistema rodando de forma invisível e reiniciará o painel caso o servidor seja desligado ou atualizado à noite.

  1. No CMD (aberto como Administrador), instale o PM2 globalmente: 
    npm install -g pm2
  2. Instale o utilitário que liga o PM2 junto com o Boot do Windows: 
    npm install -g pm2-windows-startup
pm2-startup install
  3. Ligue o Infoboard (lembre-se de estar dentro da pasta C:\Sistemas\Infoboard): 
    pm2 start server.js --name "Infoboard-TV"
  4. Salve a configuração para ele memorizar esse serviço: 
    pm2 save
✅ PRONTO! IMPLANTAÇÃO CONCLUÍDA.
A partir de agora, ninguém precisa abrir nenhuma janela no servidor. Basta acessar o painel de qualquer TV ou PC da empresa digitando o IP do servidor no Chrome/Edge. (Exemplo: http://192.168.1.100:3000).

2. COMO ATUALIZAR O CÓDIGO NO FUTURO

Sempre que você fizer melhorias no painel no seu computador de testes e quiser enviar para o servidor, siga estes 3 passos simples:

  1. Copie os arquivos novos: Copie do seu computador apenas os arquivos que você modificou (Ex: app.js, style.css, index.html, server.js).
  2. Substitua no Servidor: Cole esses arquivos na pasta C:\Sistemas\Infoboard do servidor, substituindo os antigos.
  3. Avise o Cão de Guarda: Abra o CMD no servidor e aplique a atualização com este comando mágico: 
    pm2 restart "Infoboard-TV"

O sistema piscará nos bastidores em 1 segundo e todas as TVs pegarão a atualização instantaneamente.
