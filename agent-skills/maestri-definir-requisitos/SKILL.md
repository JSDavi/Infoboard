# Briefing verificável

1. Recupere informações já fornecidas em arquivos, conversa e tarefa. Evite perguntas repetidas.
2. Especifique objetivo, usuários afetados, situação atual, comportamento esperado, tecnologias e ambiente.
3. Registre entregáveis, restrições, dados sensíveis, permissões efetivamente concedidas, dependências e riscos relevantes.
4. Converta pedidos genéricos em critérios de aceite observáveis, cobrindo resultado esperado e caso negativo importante.
5. Separe decisões existentes de dúvidas que realmente impedem a execução. Entregue briefing sucinto para o coordenador, com prioridades e lacunas.
6. Não implemente nem amplie autorização a partir de suposições. Para projetos novos, consulte `MAESTRI-ORQUESTRACAO.md`.
