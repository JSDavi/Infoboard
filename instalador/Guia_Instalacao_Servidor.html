🚀 Guia de Instalação e Atualização - Infoboard

Este guia explica como implantar e manter o Infoboard TV em qualquer servidor ou terminal Windows de forma 100% automatizada.

1. Instalação Automática (1 Clique)

Tudo foi preparado na pasta instalador/ no arquivo INSTALAR_INFOBOARD.bat.

  1. Abra a pasta instalador/ (ou copie ela para o novo computador).
  2. Dê dois cliques em INSTALAR_INFOBOARD.bat (ele pedirá permissão de Administrador automaticamente).
🔍 Verificação do Node.js
Detecta ou baixa/instala o Node.js LTS silenciosamente.
📥 Sincronização GitHub
Baixa a versão oficial mais recente direto do repositório.
⚙️ Assistente .env
Configura credenciais de NPX e PrixChat interativamente.
🛡️ Firewall Automático
Libera a porta 3000 para acesso de TVs e computadores.
🔄 Serviço Nativo Windows
Registra em services.msc (início automático no boot).
🖥️ Atalhos no Desktop
Cria atalhos para Abrir o Painel e Atualizar com 1 clique.
✅ Pronto! O painel já fica rodando em segundo plano e pode ser acessado na rede pelo endereço http://IP_DO_SERVIDOR:3000.

2. Como Atualizar o Sistema

Sempre que fizer alterações no código no seu computador e subir para o GitHub:

  1. No servidor/terminal, dê dois cliques em instalador\ATUALIZAR_INFOBOARD.bat (ou no atalho da Área de Trabalho).
  2. O script para o serviço com segurança, baixa as novidades, instala dependências e reinicia o servidor em segundos sem perder as configurações do .env.

3. Desinstalação

Caso precise remover o serviço e limpar regras de firewall, basta executar instalador\DESINSTALAR_INFOBOARD.bat.
